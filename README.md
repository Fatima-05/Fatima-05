## 🚀 Featured Projects

**🤟 PSL Vision: Real-Time Pakistan Sign Language to Urdu Subtitles**
`Python` `TensorFlow/Keras` `MediaPipe` `OpenCV`
Turns Pakistan Sign Language gestures from a live webcam feed into Urdu subtitles. A Keras network (dense + batch-norm layers) classifies 37 Urdu alphabet signs from 42 MediaPipe hand-landmark inputs, with confidence-based prediction and temporal smoothing for stable output.

**📝 GradeScan: Automated OMR Quiz Scanner & Grading System**
`React` `Vite` `JavaScript` `Node.js`
Grades MCQ answer sheets automatically. The CV pipeline is written from scratch (Otsu thresholding, connected-component corner detection, 4-point homography) and runs in both the browser and Node.js. Includes QR-based answer keys, OCR for student details, batch CSV reports, negative marking, and an analytics dashboard.

**✈️ Flypass Quantum: Airline Management System**
`Java` `JavaFX` `MySQL`
Full-stack desktop app with MVC + DAO architecture, USB-based hardware authentication (SHA-256), role-based access control, flight booking, duty scheduling, and visa processing.
